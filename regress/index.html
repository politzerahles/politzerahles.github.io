REGRESS(): The game of the General Linear Model

This is a game to help people learn how to understand regression coefficients. I am pretty confident that it's the world's most popular multimedia card game about regression coefficients.

Below are all the materials you need to play the game, teach with it, and/or make your own copy of it.

  • Game interface for simple bivariate regression (.zip file with code)
  • Game interface for multiple regression (.zip file with code)
  • Instruction manual and teaching notes
  • PDF of game cards (to make a deck, print 3 or 4 copies set to "9 pages per sheet", and cut them out)
  • Sample of scoring spreadsheet [.xlsx]
